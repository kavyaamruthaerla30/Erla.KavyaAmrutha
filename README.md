## How to Run
1. Install Python 3.
2. Open a terminal in `01_Source_Code`.
3. Run a program with `python filename.py` (replace the filename with the required file).
4. Enter the requested input.

## Learning Outcomes
- Apply selection, iteration, functions, strings, lists, tuples, dictionaries, and matrices.
- Validate user input and handle practical constraints.
- Test program behavior using normal, boundary, and invalid inputs.
- Organize and publish programming work using GitHub.
